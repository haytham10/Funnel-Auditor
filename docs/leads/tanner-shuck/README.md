**Rank 1 — live $79 checkout still headlines a cohort date 89 days gone**
Depth: DEEP · Type: stale urgency mechanic on a revenue-facing page
Innocent explanation: this is an evergreen challenge Tanner re-runs; the April 18 cohort date and countdown timer were hardcoded for that launch and simply never reset when the cohort passed (the offer itself still delivers instantly on purchase per the FAQ).
Why it matters: the $79 checkout page — the exact moment the buyer enters card details — still headlines "Next Challenge officially starts April 18th - Space is Limited!", a date 89 days in the past. It reads as "I already missed it / this is abandoned" at the point of payment, which is the single worst place on the whole funnel for that message to sit. Show: the live checkout (truestrength.co/offers/UsjagDeU) with the red "Next Challenge officially starts April 18th - Space is Limited!" line, then the challenge sales page with the countdown frozen at 00:00:00:00. Fix: in Kajabi, re-point the cohort date and the countdown timer to the next real start (or make it evergreen — "your challenge starts the Monday after you join") so the checkout and sales page carry a live date instead of one three months gone. Done state: a buyer at checkout sees an upcoming start date and a running timer — the "space is limited" urgency actually works instead of undercutting the sale.
